# Borsa Watch

- **BorsaWatch.apk** - l'app per il telefono Android.
- **BorsaServer.exe** + **Installa_Server.bat** + **Installa_Server.ps1** - il server per Windows. Scaricali tutti e tre nella stessa cartella, poi doppio clic su `Installa_Server.bat`.
- **Disinstalla_Server.ps1** - toglie il server dal PC.

Guida passo passo: https://github.com/simocc99/borsa-watch-android/blob/main/docs/GUIDA.md
